# THE LOCK (2026-10-31). Every requirement is pinned exactly, to the
# version the CI suite (.github/workflows/tests.yml, Python 3.12) resolved
# on 2026-10-31. The ranged pins this file had before (anthropic>=0.40 and
# the rest) let the production image's cached pip layer keep whatever was
# newest the first time it was built, so the box could be on anthropic
# 0.x, 1.x or 2.x, and editing any one line moved every unpinned package
# to that day's newest at once. tests/test_dependency_lock.py refuses a
# ranged or unbounded pin.
#
# WHAT IS NOT LOCKED. Only the 46 packages named below are pinned; each
# of them moves only when its own line does. The 86 they pull in (132
# installed on Python 3.12) are not: httpx2 and httpcore2, which carry
# every anthropic and openai request, pydantic and jiter, kombu, amqp and
# billiard under Celery, Twisted under daphne, certifi, urllib3, and the
# build backend of ta's sdist among them. Whenever the image's pip layer
# is rebuilt (any edit to this file, or --no-cache), pip resolves those
# again to that day's newest within their parents' ranges, so a rebuild
# matches the set CI ran on only while nothing newer has been released.
# Pinning them here too is the operator's call; the Dockerfiles and CI
# read only this file, and the lock test accepts == lines.
