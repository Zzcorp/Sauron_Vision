{% comment %} Chart.js loader. Include with: {% include "_chart_assets.html" %} and draw through the ready hook, never straight after the include: window.svChartJsReady(function () { ... new Chart(...) ... }); Every includer is an htmx fragment (/htmx/metrics/*). htmx re-creates the scripts of what it swaps in: the library's script tag came back as a script that loads in the background, while the inline chart code after it ran at once, so `new Chart` threw "Chart is not defined" and /signals/ drew no chart (2026-11-06). Nor could a request flag guard the library: each fragment is a request of its own, and `request.chart_assets_loaded` was never set by anything. So the guard is the page's. The script below runs at every include. The first include on a page adds the library's script element and the ready hook; the library's load event sets the theme's defaults and runs what the hook was handed. Later includes (the signals fragment refreshes every minute) find the library or its script on the way, add nothing, and their charts draw at once. A load that fails is said in the console, and the next include tries again. {% endcomment %}
