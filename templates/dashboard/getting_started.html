Step 1 — Get Your API Keys

Sauron Vision needs API keys to fetch market data and run AI analysis. Here's where to get each one:

ANTHROPIC (Claude AI) — Required
  1. Go to console.anthropic.com
  2. Create an account or log in
  3. Go to API Keys → Create Key
  4. Copy the key and paste it as ANTHROPIC_API_KEY in your .env file
  5. Add credit ($5-10 to start) under Billing
Note: This is separate from your Claude Max subscription. The API is pay-per-use.
ALPHA VANTAGE — Required (Free)
  1. Go to alphavantage.co/support
  2. Fill in the form → instant free API key
  3. Set as ALPHA_VANTAGE_API_KEY in .env
FRED (Macro Data) — Recommended (Free)
  1. Go to FRED API Key page
  2. Create a FRED account → request API key
  3. Set as FRED_API_KEY
eTORO — Optional (for position sync)
  1. Log into eToro web platform
  2. Go to Settings → API
  3. Generate an API key (account must be verified)
  4. Paste it in the Setup page
  5. Docs: api-portal.etoro.com
Step 2 — Configure Your .env File

Open the .env file in your project root and fill in your keys:

ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
ALPHA_VANTAGE_API_KEY=your-key-here
FRED_API_KEY=your-key-here
TWELVE_DATA_API_KEY=your-key-here
FINNHUB_API_KEY=your-key-here
ETORO_API_KEY=your-etoro-key-here
TELEGRAM_BOT_TOKEN=your-bot-token
TELEGRAM_CHAT_ID=your-chat-id
Step 3 — Start the Platform

Once your keys are set, start the Celery workers to begin data collection:

# Terminal 1 — Django web server
python manage.py runserver

# Terminal 2 — Fast worker (prices, news, signals)
celery -A config worker -l info -Q fast,default -c 4

# Terminal 3 — Slow worker (AI agents, analysis)
celery -A config worker -l info -Q slow,ai -c 2

# Terminal 4 — Beat scheduler (automated tasks)
celery -A config beat -l info

On Render.com all workers start automatically from render.yaml.

Step 4 — Set Up Your Portfolio

Go to ⊡ Setup to:

  • Set your initial capital and base currency
  • Configure risk limits (max exposure, max loss, correlation threshold)
  • Connect eToro to auto-sync positions
  • Or manually add your existing positions

Once configured, the dashboard will populate with live data as the scrapers and AI agents begin their work.
