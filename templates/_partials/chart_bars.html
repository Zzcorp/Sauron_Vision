{% comment %} Column chart — one implementation for every "bars in a card" surface. Replaces the flex-of-divs idiom that was copy-pasted across the cost trend, the score histogram, the monthly P&L and the session pulse. That idiom had three failures this partial exists to prevent: 1. The bar height was a PERCENTAGE of a fixed-height flex column that ALSO contained a value label and a date label. At the peak value the bar took 100% of the column on its own, so the two labels pushed the content past the container and the date row printed over the card's bottom edge. 2. Each column carried an unbreakable mono value ("$0.0034"). A flex item will not shrink below its content's min-content width, so seven of them set a floor the card could not go under — the card scrolled sideways on a phone. The exact value now lives in the bar's (native tooltip) and the peak lives in the caption, and the tick row is allowed to ellipsise, so the chart shrinks to any width. 3. A day with no reading and a day measured at zero drew the same nothing. Here `value: None` draws a muted "not measured" marker whose tooltip is an em-dash, while a measured 0 draws no bar at all against a baseline that is always painted — so the zero is visible AS a zero, and the two states cannot be confused for each other. Geometry lives in the template, in one viewBox, so no CSS rule can override the coordinate space the numbers were computed against.
