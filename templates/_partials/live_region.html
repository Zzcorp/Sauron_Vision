{% comment %} Keeps a page's numbers alive without reloading it. Parameters live_url the endpoint that re-renders this page's live regions How it works Every region the page wants kept fresh carries data-sv-live="", and every value inside one carries data-sv-live-key="". This fetches live_url (which renders the SAME template through dashboard/_live_shell.html), matches regions by name, swaps the ones whose markup actually changed, and flashes the values whose text differs from what the operator was reading. Why it is shaped this way - base.html owns the ONE /ws/eye/ socket and re-dispatches every payload as sv:eye-event. A page that opened its own connection to the same endpoint to watch the same events would buy nothing and cost a per-user channel. - fill_open / fill_close / close_pending are the three kinds that move a position book. The headband refreshes on exactly that set, so the two cannot disagree about what just happened. - The socket announces fills. It says nothing about a QUOTE moving, and the P&L on this page is marked to quotes — so a slow sweep is still needed, at one fetch a minute rather than a poll every few seconds. - When the socket is down the shell has already dropped to a 20s catch-up poll and marked the bell offline. This matches that cadence instead of adding a second, faster clock of its own, and the region header says so. - Absolute values from the server, never client-side deltas: one missed message and a delta drifts forever. {% endcomment %}
