One inline sprite per page, read by : no font, no CDN, no colour emoji on any machine. The tower (Barad-dûr) is the watermark's mark. Display only. Each icon's svg element carries the viewBox of the symbol it uses (every symbol here is 0 0 24 24), so its geometry is its own coordinate space and not whatever its CSS box is that render (tests/test_chart_surfaces.py, ViewBoxTests: every inline svg declares one). The sprite itself states the same grid: its box is 0 x 0 (sv-frame.css), so it draws nothing; a use element draws its symbol in the icon's own viewport. {% endcomment %}
